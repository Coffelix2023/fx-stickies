复现便签，但不做系统便签。

保留它的窗口契约：一便签一窗口、可拖背景、置顶、半透明、折叠成脊条。入口改到菜单栏。下面这张桌子就是成品要长成的样子。

为什么不用 macOS 自带便签

缺口系统便签这里
1所见即所得 富文本，不是 Markdown 排版 正文即排版。成品用 Tiptap 或 Plate，存 JSON
2一张纸里的分页 便签一多只能再开窗口 同一便签内用整行 Tabs 切换，不必为每段话新开一张
3贴进来的格式 默认带上来源字体、颜色、链接样式 外部文本只留纯文字，并入当前正文样式
4顶部控件 原生按钮很小，不好点 脊条上的字按钮至少 26px 高，置顶 / 半透明 / 折叠都在纸上
5日常操作放哪 左侧一排用不到的菜单 只留托盘：颜色、点阵/方格、显示或隐藏、图像随宽度缩放、同一便签分栏

从系统便签留下的契约

  • 无 Dock，Accessory
  • 托盘出菜单，不靠左键单击事件
  • 可见便签才开窗口，label = uuid
  • 默认 300×200
  • 置顶 = 普通窗口之上
  • 半透明 ≈ alpha 0.75
  • 折叠记住展开尺寸，并禁止缩放
  • notes/<uuid>.json，临时文件再 rename
  • 屏幕对不上时落回可见区域
  • 默认底色不用系统黄，改为象牙
